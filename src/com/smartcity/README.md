# 🌆 Smart City Tourist Guide

A Java Swing based desktop application that helps users explore
tourist places and hotels available in different cities.

## 📌 Features

- City selection
- Tourist places
- Tourist categories
- Place details
- Hotel information
- Hotel search
- Hotel sorting
- Ratings and prices
- MySQL database integration
- Java Swing GUI

## 🛠️ Technologies Used

- Java
- Java Swing
- JDBC
- MySQL
- Git & GitHub
- VS Code

## 🗄️ Database

The application uses MySQL to store:

- Cities
- Tourist places
- Hotels

## ▶️ How to Run

1. Clone the repository.
2. Open the project in VS Code.
3. Configure MySQL.
4. Update database credentials in `DBConnection.java`.
5. Create the required database tables.
6. Add the MySQL JDBC driver.
7. Run `SmartCityGUI.java`.
